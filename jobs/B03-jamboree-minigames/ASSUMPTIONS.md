# Assumptions

Catalogue scope is the union of base minigames and the 20 TV additions. This does not imply every base minigame can be played in the separate TV application. Each named Showdown is one row, including Mario's Three-peat with three embedded rounds.

Unknown gameplay values remain null. PhoneFit will be an original editorial judgment, not a Nintendo compatibility claim. No console, installed game version or gameplay execution is available.
