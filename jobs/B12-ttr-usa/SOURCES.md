# Sources and every fact row

Each row has two independently authored inventories/explanations. Mirrors of the same Matt Gawarecki dataset are one source author, never counted twice. Quotes of mathematical tables/card inventories report factual labels and values; ellipses explicitly mark omitted JSON fields. City aliases are normalized as documented in ASSUMPTIONS. Computed counts/totals cite complete source inventories and state their derivation.
