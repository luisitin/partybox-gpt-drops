Easing and springs, side by side

The top rows put the browser's own cubic-bezier() next to cubicBezier() from motion.ts. Both run the same curve over 1.2 s. The spring rows use spring(). Each tick marks settleTime(), a bound: after it, the spring is within 0.001 of rest.

Named easings

Top lane: the browser animates the transform. Bottom lane: motion.ts computes each frame. The dots should stay together.

Springs

Mass 1, displaced by 1 from rest, at rest. Stiffness k, damping c. The plot shows the position against time, with the bound marked.

API

spring(t, m, k, c, x = 1, v = 0)   -> [displacement, velocity]
settleTime(m, k, c, x, v, e = .001) -> seconds (a bound, never early)
cubicBezier(p, a, b, c, d)          -> eased progress, CSS-equivalent
easings['ease-in-out'](t)           -> the four CSS named curves

No network and no libraries. This page runs the code from dist/motion.js, inlined by tools/make-demo.mjs. Dots move with transform only; the settle marks fade with opacity.
