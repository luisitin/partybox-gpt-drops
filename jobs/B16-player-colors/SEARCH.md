# Palette search and exact delivered representation

Three seeded initial searches executed 5 × 65,000 moves each: 975,000 moves total. Seeded neighborhood refinement and simultaneous two-color neighborhoods followed; raw reports/logs are committed in `reports/search/`. The best 8-bit palette satisfied all contrast gates and the first-eight normal gate, but had three CVD deficits: Rose/Teal protan 11.994253404070554, Rose/Teal deutan 11.99774657286651, and Orchid/Cobalt deutan 11.982406196636056. This was a local-search result, never an impossibility proof.

Root then ran an independently written continuous SLSQP refinement with explicit common distance margin and luminance constraints. `continuous-run.log` preserves the actual result: one 500-iteration unsuccessful attempt followed by a successful deterministic seeded restart. `continuous-result.json` preserves the unrounded continuous and nearest-16-bit candidates. The independently authored sealed reference rechecked 600 original acceptance conditions across both candidates, recorded in `root-independent-check.json`. The full job suite rechecks the adopted 16-bit candidate against both implementations.

The continuous optimizer used deliberately conservative luminance limits 0.11883475895072134 and 0.2712141434198072. Its `quantized16ContrastPass: false` describes those additional safety limits after quantization. The original dual-background contrast requirement allows luminance 0.11881475895072134 through 0.2712341434198072. The adopted quantized candidate passes those original contrast requirements, as full-precision contrast tables and the independent suite show.

`tools/continuous.snapshot.py.txt` is the exact root source that ran. `tools/continuous.py` changes only the two absolute input/output paths to paths within this job. `reports/search/root-check.snapshot.mjs.txt` preserves the actual independent check script without portability edits. Optimization is optional author tooling with NumPy/SciPy dependencies; delivered TypeScript generation, math, PNG encoding, and tests use no runtime dependencies beyond Node built-ins in their I/O harness.

Canonical palette channels are the listed integer/65535 fractions. Exact decimal CSS serialization round-trips each binary64 vector; normal PNG samples exactly reconstruct those vectors. Hex approximations are provided for inspection only. Acceptance never substitutes an approximate hex or rounded displayed table value for an actual delivered color.
